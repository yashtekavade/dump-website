A systems-programming exercise: implementing a working filesystem using FUSE, which lets userspace code handle filesystem calls (read, write, list directories, etc.) without touching kernel code directly.

**Why it's here**

A good marker of lower-level curiosity outside the usual data-pipeline work — understanding how a filesystem actually intercepts and services I/O calls, not just consuming one.
